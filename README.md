# Air Quality Analysis (2015–2024)

**YBI Foundation AI/ML and Data Science internship final project.**

## Overview
This project explores air-quality data from 2015 to 2024 using Python and a Jupyter notebook. It brings together data inspection and visualization to examine how air quality varies across dates, cities, and monitoring stations.

## Project files
- [Analysis notebook](./Examining_Air_Quality(2015_2024).ipynb) — exploration and visualizations.
- [Air quality datasets](./Air_Quality_Data.zip) — packaged data files.
- [Project PDF](./YBI_Final_ProjectExamining_Air_Quality(2015_2024).pdf) — accompanying documentation.

## Data explored
The project uses city-level and station-level daily/hourly data, plus station metadata:
- `city_day.csv`, `city_hour.csv`
- `station_day.csv`, `station_hour.csv`
- `stations.csv`

## Analysis themes
- **Data inspection:** examine structure, types, and summary statistics.
- **Time patterns:** investigate trends across years, seasons, and hours.
- **Location differences:** compare observations by city or station.
- **Pollutant relationships:** explore associations between measured pollutants and AQI.

## How to review
Start with the notebook to see the actual analysis. To reproduce it, extract the dataset archive and adapt any local file paths used by the notebook.
